# Tap Metronome

A single-file metronome with tap tempo. Open `index.html` in a browser, no build step needed.

- **Tap/click anywhere** in the top area (or press **Space**) in time with the music to measure the BPM. It averages your last 8 taps. A pause of more than 2 seconds starts a new measurement.
- **Start/Stop** plays a click at the current BPM. The first beat of each bar is accented.
- **−5 / −1 / +1 / +5** fine-tune the tempo. **Beats** sets the beats per bar. **Reset** clears everything.
